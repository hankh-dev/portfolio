"React로 할까요, Next.js로 할까요?" 자주 받는 질문입니다. 정답은 언제나 **무엇을 만드느냐**에 달려 있습니다.

## 순수 React가 어울릴 때

- 로그인 뒤에서 동작하는 대시보드형 앱
- SEO가 거의 필요 없는 내부 도구
- 매우 화려한 인터랙션 중심의 단일 페이지

Vite와 React 조합은 가볍고 빠릅니다.

## Next.js가 어울릴 때

- 검색 노출이 중요한 서비스나 포트폴리오
- 블로그, 마케팅 페이지가 함께 있는 사이트
- 서버 렌더링이나 라우팅을 직접 구축하기 싫을 때

## 요약

| 기준 | React (Vite) | Next.js |
| --- | --- | --- |
| SEO | 약함 | 강함 |
| 초기 설정 | 매우 단순 | 약간의 학습 |
| 배포 | 자유로움 | Vercel과 궁합 |

고민된다면 대개 Next.js가 더 넓은 선택지를 남겨줍니다.
