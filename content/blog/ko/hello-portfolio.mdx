포트폴리오를 새로 만들었습니다. 이전에는 정적인 한 페이지짜리였는데, 이번에는 블로그와 다국어까지 담을 수 있는 구조로 바꿨습니다.

## 왜 Next.js 인가

가장 큰 이유는 **검색 노출**과 **글쓰기**였습니다. 포트폴리오는 결국 누군가에게 발견되어야 의미가 있고, 서버 사이드 렌더링과 정적 생성은 그 목표에 잘 맞습니다.

- 파일만 추가하면 페이지가 되는 라우팅
- 이미지 최적화가 기본 제공
- MDX로 글과 컴포넌트를 함께 쓸 수 있음

## 코드 한 조각

다크모드는 `next-themes`로 간단하게 처리했습니다.

```tsx
const { resolvedTheme, setTheme } = useTheme();

<button onClick={() => setTheme(resolvedTheme === "dark" ? "light" : "dark")}>
  테마 전환
</button>
```
